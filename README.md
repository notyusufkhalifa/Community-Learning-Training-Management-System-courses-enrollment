# Project Specification
CLTMS is a web-based system (Arabic and English, mobile-friendly) that manages the courses of a community learning center and the enrollment of learners. Learners can browse the course catalog, search by name or category, register and enroll online, and receive confirmation. The system controls seats automatically, keeps a waiting list, records payments and receipts, tracks attendance and issues certificates. Staff and trainers manage courses, classes and learners from one place, and the manager gets enrollment, attendance and revenue reports on demand.
